# Sample platformer (bundled demo)

The `platformer_demo` target showcases the Whiskers ECS: movement, combat, pickups, two small levels with a light **parcel delivery** flow (NPCs + trigger zones), moving platforms, and an **ImGui** editor.

Full games built on this engine typically live in separate repositories and consume Whiskers as a **git submodule** or installed CMake package.

See [testing-debug-protocol.md](testing-debug-protocol.md) for automated testing and the JSON stdio debug protocol.
